# Mode: init

Bootstrap a new spec-driven development project in the current directory.

## Arguments

- `text` — project description (required)

## What to Create

```
.docs/
├── planning/
│   ├── epics/       ← epic documents live here
│   └── features/    ← feature documents live here
└── specs/
    ├── backlog/     ← specs being drafted/refined
    ├── ready/       ← specs ready for implementation (.kiro/specs/ symlinks here)
    └── archived/    ← completed or retired specs

.kiro/specs -> ../.docs/specs/ready/   ← symlink (created automatically if .kiro/ exists)
```

## Steps

1. **Check for existing project** — if `.docs/planning/` already exists, confirm before proceeding. Offer to cancel or re-initialize.

2. **Confirm with user** — show the directory structure that will be created and ask for go-ahead.

3. **Create directories** — create the folder structure above. Do not create placeholder files; empty directories are fine.

4. **Check for Kiro** — check whether a `.kiro/` directory exists in the project root.
   - If it exists and `.kiro/specs` does not already exist, ask the user: "I found a `.kiro/` directory — would you like me to set up the symlink so Kiro points to `.docs/specs/ready/`?"
   - If they say yes, run: `ln -s ../.docs/specs/ready .kiro/specs`
   - If `.kiro/specs` already exists, note it and skip.
   - If `.kiro/` does not exist, skip silently.

5. **Create CLAUDE.md** — generate a project-level CLAUDE.md using the project description. Include:
   - Project name and one-paragraph description
   - Reference to the indez skill for planning workflows
   - Reference to spec-best-practices for spec conventions
   - Note that epics are optional for small projects

6. **Confirm completion** — list what was created and suggest the next step: `/indez plan --type feature` to create the first feature (or `--type epic` if the project warrants one).

## Notes

- Do not create steering documents — those belong in the project itself, not generated by init
- Do not create example epics, features, or specs — start clean
